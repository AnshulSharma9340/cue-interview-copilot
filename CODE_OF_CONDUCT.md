# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give constructive feedback and keep discussions on topic. Harassment, personal attacks and discriminatory language aren't tolerated.

To report unacceptable behaviour, contact the maintainer through a [private security advisory](https://github.com/AnshulSharma9340/cue-interview-copilot/security/advisories/new) or a direct message on GitHub. All reports are reviewed and handled confidentially.
